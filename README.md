# HR Analytics Dashboard – Tableau

## 📌 Project Overview
This project presents an interactive HR analytics dashboard built using Tableau to support data-driven decision-making for HR managers. The dashboard combines high-level workforce summaries with detailed employee records, enabling effective analysis of hiring trends, workforce composition, performance, and salary patterns.

---

## 🎯 User Story
As an HR manager, I want a dashboard that provides both summary-level insights and detailed employee information so that I can analyze workforce patterns, monitor HR performance, and make informed decisions related to hiring, retention, and compensation.

---

## 📊 Dashboard Views

### 1️⃣ Summary View
The Summary View provides a high-level overview of key HR metrics and trends.

**Overview**
- Total hired, active, and terminated employees  
- Yearly trend of hiring vs. termination  
- Employee distribution by department and job title  
- Workforce comparison between headquarters (New York) and branch locations  
- Geographic distribution of employees by city and state  

**Demographics**
- Gender ratio analysis  
- Employee distribution across age groups  
- Education-level distribution  
- Relationship between education level and performance ratings  

**Income Analysis**
- Salary comparison across education levels for male and female employees  
- Age vs. salary trends within departments  
- Identification of salary patterns and potential disparities  

---

### 2️⃣ Employee Records View
This view provides a detailed, filterable table of individual employee records, allowing deeper employee-level analysis.

**Fields Included**
- Employee Name  
- Department  
- Position  
- Gender  
- Age  
- Education  
- Salary  

Users can apply filters across any field to explore specific employee segments.

---

## 🛠️ Key Features
- Interactive filters and navigation buttons  
- Clear separation between summary insights and detailed records  
- Department, location, demographic, and salary analysis  
- Well-defined KPIs for quick insights  
- Designed for HR reporting and workforce planning
